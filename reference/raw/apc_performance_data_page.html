Performance Data

APC Propeller Performance Data

The performance data files available on our website are an excellent source for comparing APC propellers to one another.

A proprietary analysis software is used to create the performance data, using actual propeller geometry. The propeller blade loads, and resulting performance data, are generated using a specialized computational method that is based on Vortex theory. The software is continuously being updated and improved. As a result, performance files now include a software version and simulation date in the header. In addition, performance files for Marine (underwater) propellers are also available below.

Please see more on our analytical methods and future objectives here. If you cannot find performance results for a specific propeller, please contact us.

A comprehensive set of wind tunnel experimental data can be found on the UIUC Aerospace Engineering website:
m-selig.ae.illinois.edu
